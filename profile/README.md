## Featured project

### Codex Usage Monitor

A lightweight, unofficial Windows widget for monitoring OpenAI Codex usage limits.

- 5-hour and 7-day usage windows
- Reset countdowns
- Compact and full modes
- System tray and always-on-top support
- Optional Windows autostart
- Local operation with no telemetry
- Windows 10/11 x64
- Open source under the MIT License

**[View repository](https://github.com/MenghesTech/Codex-Usage-Monitor)** · **[Latest release](https://github.com/MenghesTech/Codex-Usage-Monitor/releases/latest)**

> Codex Usage Monitor is an unofficial community project and is not affiliated with or endorsed by OpenAI.
